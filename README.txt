AIRLINE FLIGHT OPERATIONS DASHBOARD — HOST-READY PACKAGE

WHAT IS INCLUDED
- index.html      : complete interactive dashboard
- data.js         : embedded airline dataset used by the dashboard
- assets/         : artwork/icons taken from your uploaded Power BI file
- README.txt      : this file

HOW TO PREVIEW
1. Keep index.html, data.js and the assets folder together.
2. Open index.html in Chrome/Edge.
3. Internet access is required for the Chart.js library loaded from jsDelivr.

FREE HOSTING OPTION A — GITHUB PAGES
1. Create a free GitHub account/repository.
2. Upload ALL files from this folder to the repository root.
3. Repository > Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /(root), Save.
6. GitHub will give you a public HTTPS URL.
7. Use that URL directly in your portfolio, or embed it with an iframe.

FREE HOSTING OPTION B — NETLIFY
1. Sign in to Netlify.
2. Add new site > Deploy manually.
3. Drag and drop this whole folder (or this ZIP).
4. Netlify provides a public HTTPS URL immediately.

PORTFOLIO EMBED
Replace YOUR-DASHBOARD-URL with the public URL:

<iframe
  src="YOUR-DASHBOARD-URL"
  style="width:100%;height:900px;border:0;border-radius:16px"
